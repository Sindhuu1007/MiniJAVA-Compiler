# CD

Compiler-design coursework implementations for the CD track.

## Assignments

| Assignment | Main focus |
|---|---|
| **P1** | MacroJava preprocessing/translation using Flex and Bison, with expression and statement macros. |
| **P2** | MiniJava parsing, symbol-table construction, and semantic type checking. |
| **P3** | MiniJava-to-MiniIR translation. |
| **P4** | MiniIR processing and conversion. |
| **P5** | MicroIR processing with control-flow and liveness-related analysis utilities. |
| **P6** | MiniRA processing and conversion, including register/spill-related support. |

## Exploring

Navigate to the assignment of interest from the repository root:

```bash
cd CD/P2
```

Each assignment is independent and may have its own grammar, parser, AST/visitor infrastructure, checklist, or test files. Consult these files for exact build and execution instructions.
