# ACD P2 — Translation

This assignment parses a MiniJava-like source program and translates it using collected class/member information.

## Implementation

- **Entry point:** `P2.java` parses standard input.
- **Symbol information:** the implementation collects class, inheritance, and member information.
- **Translation:** a translator traverses the parsed program and produces translated output.

## Run

Compile the Java sources in this directory with the included parser and syntax-tree infrastructure. Run the `P2` entry point and provide the source program through standard input. Exact compiler commands depend on the local Java setup.
