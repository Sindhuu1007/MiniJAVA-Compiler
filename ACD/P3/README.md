# ACD P3

This assignment contains a Java-based source-language processing and translation implementation, including parser, syntax-tree, and visitor infrastructure.

## Structure

The implementation is organized under `llm/`, with the entry point `P3.java`, parser-related sources, syntax-tree nodes, and visitors.

## Run

Build the Java sources under `llm/` using the included parser/AST classes and run the `P3` entry point. The program reads input from standard input. Consult the source and grammar files for the accepted input language and expected output.
