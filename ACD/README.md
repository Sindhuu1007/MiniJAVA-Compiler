# ACD

Compiler-design coursework implementations for the ACD track.

## Assignments

- **P1** — builds program/class/method information and performs visitor-based variable analysis over a parsed program.
- **P2** — translates a parsed MiniJava-like program using collected class/member information and visitor traversal.
- **P3** — MiniJava/TACoJava-family processing and translation.
- **P4** — processing and transformation of an extended Java-like representation.

Assignment directories contain their own parser support, AST nodes, visitors, and other implementation files.

## Exploring

From the repository root, enter the relevant assignment directory:

```bash
cd ACD/P1
```

The exact build and run commands depend on the assignment; check its entry-point file and included parser/build setup.
