# MiniJAVA Compiler

A collection of compiler-design implementations and coursework projects covering front-end processing, static analysis, intermediate representations, optimization, and target-level translation.

## Repository

- [Advanced Compiler Design (ACD)](./ACD/README.md)
- [Compiler Design (CD)](./CD/README.md)

Each track contains several progressive assignments (`P1`–`P6`). See the README in each assignment directory for its implementation details and execution instructions.

## Topics

- Lexical and syntactic analysis
- Abstract syntax trees and visitor-based traversal
- Symbol tables and semantic analysis
- Type checking
- Source-to-source translation
- Intermediate representations (MiniIR, microIR, MiniRA)
- Control-flow and data-flow analysis
- Register allocation and translation

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Sindhuu1007/MiniJAVA-Compiler.git
cd MiniJAVA-Compiler
```

The assignments are independent command-line programs and may have different build and input requirements. Navigate to the relevant assignment directory and consult its README before compiling or running it.

## Disclaimer

This repository is a collection of academic compiler implementations. Supported syntax, input formats, build steps, and outputs vary between assignments.
